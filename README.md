# Alpha-Star Library

Shared Skills and Agents for **Alpha-Star**, the Mills AI Collaboration Platform. Everything here is plain Markdown, so it works with any AI tool, and the repo is also a Claude Code plugin marketplace.

## Install with Claude Code

Add the Library once:

```
/plugin marketplace add EnriqueMills/Alpha-Star-Library
```

Then install a plugin by name:

```
/plugin install kitchen@alpha-star-library
```

## Use with other AI tools

Open the plugin's folder under `plugins/` and copy the instructions from an Agent file (`agents/*.md`) or a Skill (`skills/*/SKILL.md`) into your tool.

## What's in the Library

| Plugin | Agents | Skills | What it's for |
|--------|--------|--------|---------------|
| `kitchen` | Chef | meal-planning | Meal ideas, weekly plans and shopping lists |
